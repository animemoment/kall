## 1. Сетка

- **Ширина: 16 ячеек.** Нумерация линейная: `0…89`.
- Ячейка `n`: `col = n % 16`, `row = n / 16`, `x = col * 64`, `y = row * 64`.
- 90 иконок занимают **6 рядов**: последний ряд — `80…89`, ещё 6 ячеек (`90…95`) свободны.
- Холст: **1024 × 384 px** (16 × 6 ячеек).
- Ячейка: **64 × 64 px**, RGBA, прозрачный фон. Рисунок может занимать всю ячейку;
  поле 2 px делает UI по `trim` (см. §8), исходник не пересэмплируется.
- Файл: `ui/assets/textures/resources_raw/src/<id>_64.png`.
- Итог: `resources_raw_atlas.png` + `resources_raw_atlas.json`.

> **2026-11-02, проверка раскладки.** В исходном `Natural resource.png` после
> ячейки 45 оказалась лишняя каменная иконка, из-за чего ресурсы 46…89 лежали
> со сдвигом на одну клетку. Лишняя ячейка убрана, атлас и JSON пересобраны.
> Проверочные якоря: 46 — `oil_light_paraffinic`, 48 — `natural_gas_dry`,
> 61 — `stone`, 89 — `ice`.
- Промтовары позже: `resources_prom/…` — отдельный атлас, сюда не подмешивать.

### Как считать

```
номер 37  -> col = 37 % 16 = 5,  row = 37 / 16 = 2  -> x = 320, y = 128
номер 89  -> col = 89 % 16 = 9,  row = 89 / 16 = 5  -> x = 576, y = 320
```

## 2. Иконка или предмет — это разные ассеты

Ты рисуешь **иконки**, а не предметы. Это два разных слоя:

| | Иконка (сейчас) | Предмет в мире (потом) |
|---|---|---|
| Где | склад, инвентарь, рынок, рецепты, тултипы | на земле, в руках, на складе как объект |
| Размер | 64×64, читается на 32 | 64×64 в масштабе тайла (сейчас 44 px) |
| Что | символ: бревно, мешок, капля, бочка, пламя | физический объект: бревно, мешок, бочка, ящик |
| Для жидкости/газа | капля, бочка, пламя, облако | **тара** (бочка, канистра, баллон) или ничего |

Правила:
- Иконка не обязана быть физически точной. Она должна быстро читаться.
- Для твёрдого сырья иконка может быть самим предметом (бревно = бревно).
- Для жидкости/газа иконка — символ, а в мире — тара. Лужу нефти на земле не рисуем.
- Один ресурс = одна иконка. Тара — отдельный спрайт, не часть иконки.

## 3. Жидкости и газы: не предметы, а потоки

Нефть, газ, вода, молоко — это **не то, что колонист поднимает с земли**.
В 1920-х их перевозят в таре, а по заводу — по трубам.

| Ресурс | Иконка (UI) | В мире | Тара 1920-х |
|---|---|---|---|
| Нефть | капля/бочка | бочка, цистерна, вышка | деревянная бочка 159 л, стальная бочка |
| Природный газ | пламя/облако | **не носят**; трубопровод, газгольдер | баллон (если бутилированный) |
| Вода | капля | ведро, бочка, водонапорная башня | ведро, бочка |
| Молоко | бутылка/бидон | бидон | молочный бидон |
| Зерно, руда, уголь, песок | мешок/куча/кусок | мешок, куча | мешок, насыпь |
| Брёвна | бревно | бревно | — |

Следствия для кода (не сейчас, но чтобы рисовать с пониманием):
- `PhysicalForm`: Solid, Bulk, Liquid, Gas, Utility.
- `Unit`: кг, л, м³.
- `WorldVisual`: ItemSprite, ContainerSprite, Facility, None.
- Газ и вода — **flow-ресурсы**: запас в хранилище и сеть, но не стек в рюкзаке.
- Разлив — декаль, не предмет.

Месторождение (нефтяная вышка, газовый выход, родник) — **объект карты**, не иконка ресурса.

## 6. Правила

1. **ID неизменен.** `iron_hematite` — навсегда `iron_hematite`. Русское название можно
   менять, id — нет (иначе сломаются сейвы и рецепты).
2. **Порядок неизменен.** Новый ресурс — только следующим номером (`90`, `91`, …).
   Старые номера не сдвигаются.
3. **Ячейку нельзя переиспользовать** под другой ресурс, даже если ресурс убрали.
4. **Файл:** один атлас `ui/assets/textures/resources_raw/resources_raw_atlas.png`;
   исходник — `ui/assets/textures/icons/Natural resource.png`.
5. Грейды — **не** отдельными иконками: одна иконка + точка/рамка грейда в UI.
6. Варианты 2×2 (как у камня) — **не сейчас**. Одна ячейка = одна иконка.

## 8. Конвейер

1. Исходник: `ui/assets/textures/icons/Natural resource.png` — 1024×384, 16×6, ячейка 64 px.
2. `python tools/pack_resources_atlas.py` — читает таблицу `0…89`, режет на ячейки,
   считает `trim` (alpha bbox), копирует атлас в `ui/assets/textures/resources_raw/`
   и пишет `resources_raw_atlas.json`.
3. `python tools/validate_resources_atlas.py` — проверяет 90 записей, индексы `0…89`,
   уникальные id, совпадение `trim` с картинкой, отсутствие наложений.
4. В коде — `AtlasTexture` с регионом `trim` (или `cell`) и вписывание в 60×60:
   `trim` даёт поле 2 px без пересэмплирования исходника.

### JSON

`resources_raw_atlas.json`:

- `atlas`: `path`, `source_path`, `source_uid`, `width/height`, `cell/columns/rows`;
- `entries[]`: `index`, `id`, `name_ru`, `category`, `cell`, `trim`.

`cell` — абсолютный прямоугольник ячейки в атласе; `trim` — alpha bbox **внутри** ячейки.
Валидатор предупреждает о 37 ячейках, где контент касается края, и 19, где он больше
60×60. Это не ошибка: UI вписывает по `trim`.
