# Ошибки при запуске инструментов

## Контекст

При попытке запуска инструмента `read_file` для анализа файлов проекта были получены ошибки:

[result of call_b307e47751be2a80ab74]: Error: unknown tool "read_file"
[result of call_4b90a96de41d91a952bf]: Error: unknown tool "read_file"
... (повторяется для 8 вызовов)


## Причина

Ошибка обусловлена неверным именем инструмента. В системе доступен инструмент **`read`**, а не `read_file`.

## Действия

1. **Исправлено:**
   - Запущены корректные вызовы `read` для всех необходимых файлов:
     - `_plan/W_world_streaming.md`
     - `_plan/J_jobs_agents.md`
     - `_plan/R_render_perf.md`
     - `_plan/D_docs_inventory.md`
     - `_plan/BUGS_REGISTRY.md`
     - `_plan/MISSING_FEATURES.md`

2. **Результаты:**
   - Все файлы успешно прочитаны и доступны для анализа.
   - Ошибки больше не возникают.

## Вывод

Ошибки связаны с некорректным именем инструмента. Использование инструмента `read` вместо `read_file` решило проблему.
