# 06. Почему за кромкой острова «пропадал мир» и висели деревья

## Симптом (со слов игрока + подтверждено в игре)
«После прогрузки местности пропадают деревья, камни и др.»; за границей колонии
видна синяя пустота с отдельными деревьями, стоящими «в воздухе»/на воде.

## Что проверялось в живой игре (порт 9092/9093/9094)
Диагностика состояния конвейера покраски стриминга (`RepaintDirty`), 1 строка / ~2 с:

```
[PAINT-DIAG] dirty=1 queued=0 jobs=0 erasing=0 loaded=16 cells=0 ...
```

То есть: чанки грузятся (`loaded=16`), очередь грязных чанков живёт, задания
покраски создаются и отрабатывают — но в слое `WorldGroundAndDecor` **ноль клеток**
в районах без декора. A/B-проверки:

| Вариант | `get_used_cells()` |
|---|---|
| `MaxCellsPerPaintSlice = 4096` (исходное) | 0 |
| `MaxCellsPerPaintSlice = 512` | 0 |
| без guard в `RemoveChunkTiles` | 0 |

Вывод: ни размер слайса, ни guard не виноваты — дело в самом `PaintCell`.

## Корень (file:line)
`src/ui/streaming/StreamingWorldView.cs`, `PaintCell`:

```csharp
if (compositeIndex == CompositeWater || compositeIndex == CompositeGrass ||
    compositeIndex == CompositeSand || compositeIndex == CompositeSteppe ||
    compositeIndex == CompositeGlacier)
    _groundLayer.EraseCell(pos);   // базовая земля НЕ рисуется тайлом
else
    _groundLayer.SetCell(pos, ...); // рисуется только декор
```

Замысел: базовую землю показывает шейдер `GroundSurface` (анимированная вода и т.п.),
поэтому стриминг её «стирает». Но шейдер наполняется только своим follow-окном и
картой колонии; сразу за кромкой 1024×1024 окно пустое → шейдер отдаёт **воду**
(нулевой индекс = вода). Декор при этом рисуется тайлами. Итог: синий фон + деревья
на воде + «мир исчезает после прогрузки».

## Исправление
В `PaintCell` базовая земля теперь **всегда** ставится тайлом:

```csharp
// Сюда (после island-гейта в начале PaintCell) попадают ТОЛЬКО клетки вне острова,
// где шейдер не авторитетен — рисуем землю своим тайлом.
_groundLayer.SetCell(pos, SrcCompositeGround, new Vector2I(compositeIndex, 0));
```

Гейт `if (cellX/cellY внутри 0..1024) return;` в начале `PaintCell` не тронут, поэтому
внутри колонии поведение прежнее (остров рисует `MapRenderer`, шейдер остаётся
источником анимированной воды).

## Доказательство ДО/ПОСЛЕ
Камера `(66000, 32768)` — за правой кромкой острова (1024·64 = 65536):

| | `used_cells` | вид |
|---|---|---|
| ДО | `0` | синяя пустота, деревья висят на воде (`_reports/forest_out.png`) |
| ПОСЛЕ | `32768` | сплошная земля + деревья (`_reports/edge_fixed.png`) |

## Побочный, но важный фикс того же файла
`RemoveChunkTiles` больше не стирает тайлы у чанка, который всё ещё нужен стримеру:

```csharp
if (_streamer != null && _streamer.IsDesired(key) && _chunkData.ContainsKey(key))
    return;
```

Иначе гонка «выгрузка → повторная загрузка» стирала только что нарисованный чанк —
это и есть «после прогрузки деревья пропали».
