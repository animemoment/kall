# Сборка игры (Windows x64)

Запуск: **`Game.exe`** (рядом должны лежать `Game.pck` и папка `data_Game_windows_x86_64`).

Содержимое:
- `Game.exe` — исполняемый файл (170 МБ, self-contained .NET)
- `Game_console.exe` — то же с консолью (для логов)
- `Game.pck` — ресурсы игры
- `data_Game_windows_x86_64/` — .NET-рантайм и сборки игры
- `ui/` — ресурсы интерфейса

Не входит (и не нужно для запуска): `GodotSharp/` (API/тулчейн редактора), `.godot/` (кэш импорта).
Крупные файлы хранятся через Git LFS — при клонировании нужен `git lfs pull`.
